# Module 4: Data Analysis

Descriptive statistics summarize data using measures such as the mean, median, mode, and percentage. Inferential statistics use a sample to draw conclusions about a population.

Choose the analysis that fits the research question. Present results in tables and charts, then interpret what they mean instead of only listing numbers.

- **Mean**: the average of a set of values
- **Median**: the middle value when data is arranged in order
- **Mode**: the value that appears most often
- **Likert scale**: a rating scale, such as strongly agree to strongly disagree, used to measure attitudes
