# Module 4: Social Media Trends

Social media lets ordinary people create and share content, so trends can spread within hours. Algorithms decide what each user sees, which can build echo chambers.

Memes, challenges, and influencers are common ways trends move online. Users should think about privacy and accuracy before sharing.

- **Meme**: an idea, image, or phrase that spreads online in many variations
- **Influencer**: a person with a large following who can shape opinions or buying choices
- **Algorithm**: a set of rules that decides what content a platform shows
- **Echo chamber**: an online space where people mostly see views like their own
- **Viral**: spreading widely and quickly online
