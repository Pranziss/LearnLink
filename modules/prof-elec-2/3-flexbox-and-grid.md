# Module 3: Flexbox and Grid

Flexbox is a one-dimensional layout model that arranges items in a row or column. Setting display to flex on a container turns its children into flex items that can grow, shrink, and wrap.

CSS Grid is two-dimensional, controlling rows and columns together. Use flexbox for components in a line and grid for whole-page layouts.

- **flex-wrap**: lets flex items move to a new line when space runs out
- **justify-content**: aligns flex items along the main axis
- **align-items**: aligns flex items along the cross axis
- **Grid template**: defines the rows and columns of a grid layout
