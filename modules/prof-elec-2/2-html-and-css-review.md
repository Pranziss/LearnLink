# Module 2: HTML and CSS Review

HTML gives a page its structure using elements such as headings, paragraphs, links, and forms. Semantic elements like header, nav, and main describe the purpose of each part.

CSS controls presentation. A rule has a selector and declarations. The box model describes how content, padding, border, and margin make up each element's size.

- **Selector**: the part of a CSS rule that chooses which elements to style
- **Box model**: the layout model of content, padding, border, and margin around every element
- **Semantic HTML**: elements whose names describe their meaning, like nav and article
- **Responsive design**: layouts that adapt to different screen sizes
