# Module 1: Web Architecture

The web works on a client-server model. A browser (the client) sends an HTTP request to a server, and the server sends back a response, usually an HTML page along with CSS and JavaScript files.

A URL identifies a resource. DNS translates a domain name into an IP address, and HTTPS encrypts the connection between browser and server.

- **HTTP**: the protocol browsers and servers use to exchange web pages
- **DNS**: the system that translates domain names into IP addresses
- **Client**: the program that requests a service, such as a browser
- **Server**: a computer that provides pages or data to clients
- **API**: a defined way for programs to request data from each other
