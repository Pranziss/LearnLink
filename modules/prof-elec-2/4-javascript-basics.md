# Module 4: JavaScript Basics

JavaScript adds behavior to a page. It can respond to clicks, change the content of elements, and request data from servers.

Variables store values using let and const. Functions group reusable code, and the DOM lets scripts read and change the page.

- **DOM**: the browser's tree of page elements that scripts can read and change
- **Event**: something that happens on a page, such as a click or a key press
- **Variable**: a named place to store a value
- **Function**: a reusable block of code that performs a task
